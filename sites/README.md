# Sites: local details for each service

Each service using this material keeps one file here with its own local details. These fill the `{{site.*}}` placeholders in documents, so the shared clinical content never needs local editing.

To add your service, copy `_example.yaml` to a new file named after your service (lower case, hyphens), fill it in, and open a pull request.

Only include information that is already public, such as published department phone numbers. Never include personal mobile numbers or anything about patients.
